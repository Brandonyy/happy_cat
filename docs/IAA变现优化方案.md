## 二、必须做的（上线前）

### 1. 开广告 + 填广告位 ID
- `adConfig.ts`：`isShowAd = true`，填入 5 个广告位 ID
  （wxBannerId / wxChaPingId / wxVideoId / dyChaPingId / dyVideoId）
- **建议改为服务端远程配置**，而非硬编码：
  - 支持灰度发布、紧急关停（kill switch）、分人群投放

### 2. 修 `showVideo` 失败兜底（`adMgr.ts:120`）
- 现状：广告拉取失败 / 未完成时 callback **完全不执行**，玩家点了按钮无反馈
- 改造：
  - 区分「用户中途退出」（不给奖励 + 提示）与「广告拉取失败」（给提示 / 视场景补偿）
  - **预加载**：每次播完立即 `createVideoAd()` 预拉下一条，提升填充率

### 3. 插屏加频控（`adMgr.showChaPing`）
- 现状：胜利 / 失败 / 进主界面都弹，连打几关会狂弹
- 平台规则：微信 / 抖音插屏间隔需 ≥30s，过频严重掉留存且违规
- 改造：加全局冷却守卫（建议 ≥30~60s）

---

## 三、提升收入（核心：激励视频渗透率）

> 激励视频通常占小游戏 IAA 收入 **70%+**。

在现有 8 个点基础上，建议新增「自然给奖」入口：

- 💰 每日福利翻倍（`onDayfl` 看广告 ×2）
- 🎁 看广告免费领道具（每日限 3~5 次，养成看广告习惯）
- 🪙 金币不足时「看广告补 200 币」
- ⏰ 限时双倍金币 buff（看广告解锁 N 分钟）
- ❤️ 二次复活 / 多看一次广告续命
- 📅 签到 / 连续登录翻倍

**关注指标**：广告渗透率（看过广告用户占比）、人均观看次数（IMPU）。

---

## 四、留存优化（IAA 下：留存 = 收入）

- **新手保护**：前 3~5 关不插任何插屏，保次留
- **第 2 关「难度飙升」(240 球) 是劝退点**：
  - 早期难度曲线需压平（详见 `docs/关卡配置表.md`）
  - 否则用户没看几个广告就流失
- 插屏只在「关卡结束」等自然断点出现，并配合频控

---

## 五、数据闭环

- 加广告打点 hook：`show / fill / complete / reward` + 触发场景来源
- 上报平台或自有后台，监控：
  - ECPM、人均广告次数、各广告位收入贡献
  - 次留 / 7 留、广告渗透率
- 基于数据做 A/B（广告位位置、奖励倍数、频控阈值）
