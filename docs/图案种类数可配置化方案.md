# 超级抓喵喵 — 每关图案种类数可配置化方案

> 目标：把「每关出现多少种不同图案」变成可配置的难度杠杆。
> 相关文件：`configs/guanqiaConfig.ts`、`configs/ballConfig.ts`、
> `scene/game/gameScene.ts`（`creatNocatLevel` / `creatCatLevel`）、
> `utils/ballUtil.ts`、`utils/arrUtil.ts`。

---

## 一、现状：无法控制每关图案种类数

游戏共 **72 种图案**（60 普通 + 12 猫，详见 `docs/关卡配置表.md` 与 `ballConfig.ts`）。

关卡生成时，对每一组（共 `fenzu` 组）都用 `suijiYuansu()` 从候选池里**随机抽一个图案**：

- **普通关**（`creatNocatLevel`）：候选池 = `getPutongBall()` = 全部 **60 种**普通图案
- **抓猫关**（每 5 关 + 挑战模式，`creatCatLevel`）：候选池 = `getTypeBall(type)` = 某一个系列（9~11 种）

因此「这关出现几种图案」是**随机涌现**、无参数控制：

- `fenzu=80` 的关（如第 2 关）几乎会把 60 种全用上 → 又乱又难找
- `fenzu` 小的关碰巧种类少，但纯靠运气，无法稳定控制

> 这是一个**被浪费的难度杠杆**：图案种类越少越好配对（简单），越多越难找（困难）。

---

## 二、改造方案（低成本、向后兼容）

### 第 1 步：给关卡配置加字段
在 `guanqiaConfig.ts` 每关加 `zhonglei`（图案种类数）：

```ts
{ id: 3, fenzu: 30, catFenzu: 0, peiduiFenzu: 25, time: 118, zhonglei: 8 }
```

### 第 2 步：改生成逻辑
在 `creatNocatLevel` / `creatCatLevel` 中，先从候选池抽 N 种不同图案组成「本关图案池」，再从小池子里取：

```ts
// 原来：每组从全部候选池随机
const data = suijiYuansu(balls)

// 改为：先固定本关只用 zhonglei 种
const levelPool = daluanArr([...balls]).slice(0, zhonglei)
const data = suijiYuansu(levelPool)
```

### 向后兼容
- `zhonglei` 不填（或 ≤0 / 超过候选池大小）时，回退到现有「全池随机」行为
- 即不影响已配好的 70 关现状，可逐关渐进调优

---

## 三、配套建议

- 给 70 关填一套**图案种类数梯度**：前期种类少更友好，后期种类多更挑战
- 与 `fenzu` / `peiduiFenzu` 配合，做出更细腻的难度曲线
- 抓猫关因候选池本身只有 9~11 种，`zhonglei` 影响较小，可主要用于普通关
