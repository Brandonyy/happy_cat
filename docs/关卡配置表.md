# 开心抓猫猫 — 关卡配置表

> 数据来源：`assets/scrpit/configs/guanqiaConfig.ts`
> 生成逻辑：`assets/scrpit/scene/game/gameScene.ts`（`initBallData` / `initLevelConfig`）

## 参数说明

| 字段 | 含义 |
|---|---|
| `fenzu` | 球的组数，每组 3 个球（**总球数 = fenzu × 3**） |
| `catFenzu` | 猫球组数，>0 即「抓猫关」 |
| `peiduiFenzu` | 配对组数量（≤fenzu），**数值越小难度越大**（预排成对的组越少，乱序组越多） |
| `time` | 关卡限时（秒），`-1` 表示不限时 |
| 类型 | 普通关 / 抓猫关（每 5 关：5、10、15…）/ 新手关（第 1 关） |

> 补充机制：
> - 场上同时显示的组数封顶 `maxZushu = 40`，`fenzu > 40` 的关卡球分批从后备队列补入。
> - 球的缩放随关卡递增逐渐缩小（有下限），后期更密更难找。
> - 猫的可选种类 `fanwei = 1 + floor(level / 5)`，越后期花样越多。
> - 通关第 70 关后，第 71 关起在第 50–70 关之间**随机抽取**，可无限循环。

## 阶段难度概览

| 阶段 | 关卡 | fenzu 范围 | 特征 |
|---|---|---|---|
| 入门 | 1–10 | 3 → 40 | 第2关飙升、第3关骤降，整体起伏教学 |
| 进阶 | 11–30 | 31 → 50 | 大量 `peidui=0` 全乱序，纯找球 |
| 高阶 | 31–50 | 61 → 80 | 球数上台阶，41+ 限时拉长但 peidui 收紧 |
| 后期 | 51–70 | 固定 90 | 球最满，靠 peidui 梯度 + 限时递减加压 |
| 循环 | >70 | — | 随机复用第 50–70 关，无限挑战 |
