# 开心抓猫猫 — 可玩性 / 趣味性优化建议

> 目标：在不改动核心玩法的前提下，用低成本改动榨出更多趣味性与留存。
> 基于现有系统盘点：三消核心（`gameScene.ts`）+ 猫图鉴 + 家园 + 抽奖 + 换肤。

---

## 一、现状评估

### 先天优势（品类已验证）
- 「点球进槽、三个一消」属羊了个羊 / 连连消式玩法，**上手 0 成本、即时反馈、天然上瘾**。
- 已有猫图鉴收集 + 家园建设 + 抽奖换肤，**养成线齐全**，留存框架不差。

### 当前短板（趣味性未拉满）
1. **打击感弱**：消除仅合并特效 + 音效，缺连击、缺爽点累积。
2. **关卡缺目标感**：每关只是"清完球"，无评分 / 星级 / 小目标，缺重玩动力。
3. **球种类单一**：仅普通球 + 猫球，无特殊球，70 关玩法高度重复。
4. **无真正终局**：70 关后随机复用，挑战模式仅 2 关，高手无去处。
5. **回访理由薄**：除每日福利外，无每日新鲜内容。

## 二、优化建议（按性价比排序）

### 🥇 P0：连击系统（改动小、爽点大）✅ 已实现
- 在 `mergeBall` 中加入：N 秒内连续消除 → 连击计数
- 叠加效果：音效音调上扬 + 屏幕轻微震动 + "Combo ×3 !" 飘字 + **连击额外奖励金币**
- 复用现有 `mergeTexiao` 特效与合并流程，**几乎零新美术**，体验提升最明显

#### 落地实现说明
- **触发**：`gameScene.mergeBall` 确认本次投球发生消除后调用 `onCombo()`，按「每次成功消除」计一连。
- **连击窗口**：`gameConfig.comboWindowTime`（默认 **5 秒**）。窗口内连续消除则累加，超时由定时器归零。
- **额外金币**：2 连起，每级 `+gameConfig.comboJinbi`（默认 2），累加到金币道具（id 0），结算 / 主界面体现。
- **震动**：复用 `apiMgr.zhenDong()`（微信端生效，抖音端为空实现）。
- **音量代替音调**：Cocos `AudioSource` 无 pitch 属性，故改为 `musicMgr.playSound(audio, volumeScale)` 让合并音随连击放大（上限 2 倍），听感同样递进。
- **常驻连击 HUD 代替瞬时飘字**：新增 `comboPiao.prefab`（黄字描边 Label），屏幕上方常驻显示「连击 ×N」并跳动强调；停顿期间保持显示，直到连击窗口超时才隐藏——解决了瞬时飘字"一停顿就看不到连击"的问题。
- **改动文件**：`gameScene.ts`、`gameConfig.ts`、`musicMgr.ts`、新增 `bundles/prefabs/game/comboPiao.prefab`。

### 🥈 P0：消除「juice」三件套 ✅ 已实现
- **飘字**：消除时 `+10` 金币、`Nice! / Great!` 文字弹跳
- **微震屏**：合并瞬间镜头 / 根节点轻抖（一次 `tween` 即可）
- **清场庆祝**：最后清空时撒花 + "Perfect!"，让"赢"有仪式感

#### 落地实现说明（降级方案，零新美术资源）
- **飘字**：新增 `gameUtil.piaoZi()`，**纯代码动态生成带描边 Label**（上浮 + 回弹 + 淡出后自毁，仿 `mergeTexiaoTs` 自毁模式），不依赖任何预制体 / 美术。
  - 连击鼓励词 `Nice! / Great! / Amazing!`：按 `gameConfig.juiceWords` 的 2/4/6 连阈值取词，在消除汇聚点弹出（2 连起）。
  - 金币奖励 `+N`：在屏幕上方弹出，数值与 `onCombo` 的连击额外金币同源。
- **微震屏**：新增 `gameScene.shakeScreen()`，衰减式多段「左右 + 上下」摆动，强度随连击递增（`gameConfig.shakeBase/shakeStep/shakeMax`）。
  - ⚠️ 关键坑：根节点 `Canvas` 带 `Widget` 会**每帧把位置拉回**，抖根节点无效；故改为**抖 Canvas 下无 Widget 的 `Camera` 渲染相机节点**，整屏统一位移且可精确复位。
  - 与既有 `apiMgr.zhenDong()`（手机马达）叠加，形成「视觉 + 体感」双反馈。
- **清场庆祝**：新增 `gameScene.qingChangCele()`，复用现有 `mergeTexiao` 特效在中心多点炸开 + `Perfect!` 大字 + 加重合并音，**1.5 秒**后再打开结算页。
  - 接入 `putongWin()` 与 `tiaozhanWin()`（level 2）两条胜利路径；兜底清场 `clearAllRemainingBalls → jianchaWin → putongWin` 自动共享，无需重复埋点。
- **改动文件**：`gameScene.ts`、`gameUtil.ts`、`gameConfig.ts`（无新增预制体 / 美术）。

### 🥉 P1：关卡三星评分
- 按「剩余时间 / 是否用道具 / 连击数」给 1~3 星，主界面关卡显示星数
- 给玩家**重玩刷分**的理由，复用现有 `time` / 道具数据即可计算

### P1：特殊球（玩法变化，复用现有管线）
在 `ballConfig` + 生成逻辑中加 2~3 种：
- 🌈 **万能球**：可与任意颜色凑成一组
- 💣 **炸弹球**：消除时连带清掉场上同色一批
- ❄️ **冰冻球**：需点两次才进槽
- 后期关卡掺入特殊球，**用极小成本让 70 关不再重复**

### P2：每日挑战 + 计分天梯
- 挑战模式当前仅 2 关，改造为**无限计分模式**（连击算分）
- 接已有 `rankPop` 排行榜 → 给高手长期目标与社交攀比

### P2：收藏的「用处」
- 12 只猫现仅收集进图鉴；给每只猫**微小被动加成**（如 +5% 金币）或"喂猫 / 撸猫"小互动
- 让收集有实感，强化养成动机

## 三、优先级总览

| 优先级 | 建议 | 改动范围 | 预期收益 |
|---|---|---|---|
| P0 ✅ | 连击系统（已实现） | `gameScene.mergeBall` 集中一处 | 时长 + 爽感，立竿见影 |
| P0 ✅ | 消除 juice（飘字 / 震屏 / 清场庆祝）（已实现） | 消除与胜利流程 | 体验质感提升 |
| P1 | 关卡三星评分 | 结算 + 主界面关卡显示 | 重玩刷分动力 |
| P1 | 特殊球（万能 / 炸弹 / 冰冻） | `ballConfig` + 生成逻辑 | 打破 70 关重复 |
| P2 | 无限计分模式 + 天梯 | 挑战模式 + `rankPop` | 高手留存 + 社交 |
| P2 | 收藏被动加成 / 撸猫互动 | 图鉴 + 数值 | 收集实感 |

## 四、首要建议

**两项 P0（连击系统 + 消除 juice 三件套）均已实现** —— 同样的关卡，加上连击爽点累积 + 飘字 / 震屏 / 清场庆祝，打击感与仪式感已显著提升，且几乎零新美术、改动集中、风险低。

**下一步若只做一件事 → P1 关卡三星评分。**

理由：
- 复用现有 `time` / 道具 / 连击数据即可算分，改动集中在结算 + 主界面关卡显示
- 给玩家**重玩刷分**的长期动力，是把已实现的连击爽点「沉淀为目标感」的最低成本一步
